## CP6r qualification before B1

These are source/test-review observations, not reproduced new test failures. The existing source hashes are `97f6e6076982d4363f60ec1e0eef65ba9693d4f01364406ab081cd8f844d06fe` (helper) and `1dab15139df0d7362d2d69fa377cceb4676da41b2b3a0a26c6d3fa181a0815e9` (five-case test).

1. The named EBUSY/EPERM/EEXIST test creates an existing recent claim, exercising EEXIST only. It does not inject EBUSY, EPERM or EACCES. Add real fault cases without assuming the label proves their handling.
2. Claim open/write happen before the later protected `try/finally`. A claim write failure can escape without that cleanup. The final cleanup still catches/discards close/unlink errors; it attempts cleanup and does not guarantee it. Test claim write/close/unlink failures, preserved primary error, bounded cleanup outcome, and restart recovery. Do not certify silent success when residue remains.
3. Stale recovery accepts a missing/zero/malformed owner (`!claimPid`) after ten seconds. That is not proof that the acquisition owner is dead. Test delayed initialization/live owner, malformed/empty markers and ambiguous read errors; no expiry-only stealing.
4. Two reclaimers can observe the same stale marker before unlink/reopen. Test coordinated competing reclaimers and replacement-ownership readback; a contention guard must protect the reclamation transaction itself, not merely the final file open. Preserve the original owner and avoid deleting a successor's marker.
5. Isolated consumer PASS does not prove the combined invocation failure pre-existed. `node --test` normally runs files in separate child processes; they can still share filesystem lock roots. Reproduce against pre-patch and current source in equivalent isolated copies, or record the cause as unconfirmed. Serializing shared-resource consumers is prudent while qualification proceeds.

The existing report is historical evidence. Qualification is within CP6r, not a new top-level checkpoint. Preserve Antigravity edits and prove/fix only the named gaps under a new exact-source receipt before declaring readiness closed.
