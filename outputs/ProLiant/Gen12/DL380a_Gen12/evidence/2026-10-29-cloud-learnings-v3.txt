1. System Foundation & Processor Rules

1.1 Dual-Socket Mandatory Population

Motherboard Architecture:

 The DL380a Gen12 platform strictly enforces dual-processor configuration. Single-socket operation is physically and logically unsupported by the motherboard signal routing and the factory configuration engine. [11]

Model Match Rule:

 Both populated processors must be identical SKUs (matching clock speeds, cache structures, and core counts). [9]

Factory Heatsink Assembly:

 In Configure-To-Order (CTO) builds (

P76706-B21

), second CPU socket hardware, high-performance air heatsinks, and thermal interface materials are automatically bundled under factory routing flag 

0D1

. No separate heatsink SKU is required unless specifying CPU Direct Liquid Cooling (DLC, 

P82520-B21

).

1.2 Base CTO Chassis Selection: iLO 6 vs. iLO 7 P-Core Mandate

Base CTO Chassis 

P74461-B21

 (with iLO 6):

 Limited. Intel® Xeon® 6 processors with Performance-Cores (P-Cores) and high-tier GPUs (e.g., RTX PRO 6000 

S6A73C

) are 

not

 supported on this chassis. [11]

Base CTO Chassis 

P76706-B21

 (with iLO 7):

 Required. Any configuration utilizing Xeon 6 P-Core processors or enterprise AI GPUs 

must

 select 

P76706-B21

. [11]

2. Storage Subsystem & Drive Cage Constraints

2.1 Prohibited Drive Cage Mixing (Rule 81016788)

The Trap:

 The DL380a Gen12 has a single front-loading storage bay. Attempting to select both a 4SFF FIO Drive Cage Kit (

P74710-B21

) and a 4EDSFF FIO Drive Cage Kit (

P74712-B21

) in the same build triggers a critical unbuildable conflict. [11]

The Resolution:

 Select exactly 

one

 drive cage style (4SFF 

P74710-B21

 or 4EDSFF 

P74712-B21

). [11]

2.2 Mandatory Storage Cabling (Rule 81016790)

4SFF Cage (

P74710-B21

):

 Requires direct-attach data cable kit 

P74702-B21

 or 

P74708-B21

.

4EDSFF Cage (

P74712-B21

):

 Requires direct-attach cable kit 

P74704-B21

. [11]

2.3 Storage Controllers & OCP Slot Over-Limit Conflicts

OCP vs. Stand-Up Slot Limits:

 The DL380a motherboard possesses 

exactly two physical OCP3 slots

 (Slot A and Slot B). Populating an MR416i-o OCP storage controller (

P47781-B21

) alongside two OCP3 NICs (

P10115-B21

) creates a 

3-OCP card over-limit conflict

.

The Resolution:

 Swap the storage controller to the stand-up PCIe form factor 

P47777-B21

 (MR416i-p Gen11 PCIe Controller) with cable 

P76700-B21

 (Tri-Mode PCIe FIO Cable). This frees OCP Slot A and Slot B for dual OCP NICs.

Cable Disambiguation:

 Do not mix 

P74696-B21

 (OCPB Cable) when a storage controller cable is attached to the 4SFF cage.

Direct-Attach VROC Alternative:

 For pure NVMe flash without hardware RAID requirements, use Intel VROC with direct-attach cables to save $12k+ per node.

3. Host Networking, Transceivers & Rear PCIe Slot Allocations

3.1 Base Chassis Networking Reality

No Default Transceivers or LOM Ports:

 The base 

P76706-B21

 chassis contains zero networking ports or transceivers out of the box (except the 1Gb RJ-45 dedicated iLO management port).

3.2 Transceiver Ratios for SFP28 Cards

Port-to-Transceiver Ratio:

 Every dual-port 25Gb SFP28 card (

P26262-B21

 or 

P10115-B21

) has 2 physical SFP28 cages.

Optics Requirement:

 Populating 1 dual-port card requires 

2x 

845398-B21

 (HPE 25Gb SFP28 SR 100m Transceivers). Populating 2 cards requires 

4x 

845398-B21

.

3.3 Fitting Dual 25GbE Cards in 8-GPU Mode (The Hybrid Option)

The Constraint:

 In 8-GPU mode (

P75008-B21

), only 1 rear PCIe expansion slot is available for stand-up cards. You cannot populate 2x stand-up PCIe NICs (

P26262-B21

).

The Optimal Hybrid Solution:

1x 

P26262-B21

 (PCIe 25GbE 2-port NIC in rear Slot 3/6)

1x 

P10115-B21

 (OCP3 25GbE 2-port NIC in OCP Slot A)

1x 

P74694-B21

 (OCPA Cable Kit)

4x 

845398-B21

 (25Gb SR Transceivers)

Financial Advantage:

 This hybrid combination provides 4x 25GbE ports, avoids slot conflicts, and saves 

$209.00 list price per node

 compared to buying 2x OCP3 cards.

3.4 Optical Transceivers vs. Direct Attach Copper (DAC) Cables

Optical Standard (

845398-B21

):

 Required whenever structured multimode fiber (OM3/OM4) or customer tender specifications mandate transceivers.

DAC Alternative (

845970-B21

):

 For in-rack connections to Top-of-Rack (ToR) switches (<5m), swapping 4x optics for 2x SFP28 DAC cables saves **~

7,986.00 list per server** (~

160k across 20 nodes).
