# Historical & Completed Task Archives (`_archive_scripts/`)

This directory safely stores historical task artifacts, completed Google Jules multi-agent sessions, deprecated one-time migration scripts, and older execution run logs to keep the active development workspace clean and token-efficient.

---

### Directory Hierarchy

- `jules_cache_archive/`: Archived local activity caches for completed Google Jules background tasks (Tasks 1 through 15 and initial architecture reviews).
- `sessions_archived.jsonl`: Consolidated session metadata log for all 22 completed Jules sessions.
- `history_runs_archive/`: Historical execution logs archived from `outputs/history/runs/`.
- `archived_fixes/`: One-time recovery scripts retained for historical reference.
