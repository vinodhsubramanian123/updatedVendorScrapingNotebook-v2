## 4. Scope Taxonomy Classification

Used by `knowledge_sync.js` to categorize rules:
1. **`UNIVERSAL_VENDOR`**: Rules applicable across all HPE enterprise servers (e.g. BTO/CTO isolation, TAA/GTA exclusions, -48VDC DC Terminal Lug Kit requirements).
2. **`FAMILY_GEN`**: Rules bound to a specific generation or product family (e.g. ProLiant Gen12 DDR5 1DPC/2DPC memory channel balance, Alletra cache battery protection).
3. **`CHASSIS_SPECIFIC`**: Rules unique to a single form factor/chassis variant (e.g. DL380 Gen12 8SFF Box 1/2 controller cable kit `P76453-B21`).

## 6. Output Translation & Modality Mappings

| Output Modality | Source Engine | Structure & Styling |
|---|---|---|
| **Dashboard UI Matrix** | `ResolutionMatrix.jsx` | 9 standardized hardware rows with `— None Required (Standard Default Included)` badges for unneeded parts. |
| **Master Catalog Excel** | `generate_xlsx.js` | **19 dedicated sheets**: `Category Summary`, `All SKUs`, `Chassis Variants` (CTO base options + prices), `Rules & Constraints`, `Hardware Accessories` (80 physical SKUs), `Software & Licenses` (432 service SKUs), `Catalog Diffs`, `Price History Timeline`, Category drilldowns (Processor, Memory, Power Supplies, Smart Chassis, etc.), `Discontinued SKUs`, `Metadata`. |
| **Corrected BOQ Excel** | `generate_boq_xlsx.js` | Multi-sheet workbook (`Summary`, `Base BOM`, `Missing Dependencies`, `Strategy Add-ons`) with Excel formulas (`=B2*E2`, `=SUM()`) and cell protection. |
| **NotebookLM Sync Payload** | `knowledge_sync.js` | Clean markdown charter note (`notebook_sync_payload_<Chassis>.md`) replacing stale sources via direct `lastSyncedSourceId` deletion before upload. |
| **System Telemetry Ledger** | `telemetry.js` | Action ledger and KPI counters stored in `outputs/history/pipeline_telemetry.json`. |
