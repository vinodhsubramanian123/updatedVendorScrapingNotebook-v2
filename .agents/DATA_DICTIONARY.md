## 3. Conflict Graph Schema (`ConflictGraph`)

Directed graph tracking hardware rules, dependency constraints, and capacity limits in `conflict_graph.js`.

```json
{
  "chassis": "DL380_Gen12_SFF",
  "nodes": [
    { "id": "P54321-B21", "type": "CPU", "tdp": 350, "qty": 2 }
  ],
  "edges": [
    { "source": "P54321-B21", "target": "P58000-B21", "type": "REQUIRES_HEATSINK", "rule": "High-TDP (>270W) requires High Performance Heatsink" }
  ],
  "conflicts": [
    {
      "level": "CRITICAL",
      "aspect": "thermal",
      "description": "Standard heatsink insufficient for 350W CPU",
      "suggestedFixSku": "P58000-B21"
    }
  ]
}
```
