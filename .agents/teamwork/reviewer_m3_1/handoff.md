## 2. Logic Chain

1. **Feature 9: Fabric Protocol Differentiation & High-Speed Cluster Interconnect**:
   - `detectFabricProtocol(text)` establishes a hierarchical match:
     - InfiniBand NDR is identified by keywords (`ndr`, `ndr400`, `osfp`, `mcx75...`, `cx7...`) alongside InfiniBand markers.
     - InfiniBand HDR is identified by `hdr`, `hdr200`, `qsfp56`, `mcx65...`, or generic InfiniBand keywords.
     - RoCEv2 is identified by explicit `roce`, `rocev2`, or Broadcom Thor/57508 / Mellanox RDMA identifiers.
     - Standard Ethernet serves as the base layer.
   - In `_evaluateNetworkingFabricParity`:
     - When competitor specifies `INFINIBAND_NDR`, target BOM must supply an NDR adapter (`INFINIBAND_NDR`); an HDR or standard Ethernet adapter is flagged as `DEFICIT` due to protocol/bandwidth incompatibility.
     - When competitor specifies `INFINIBAND_HDR`, target BOM providing NDR is recognized as `EXCEEDS` (backward compatible high-speed fabric).
     - When competitor specifies `ROCE_V2`, InfiniBand adapters are recognized as compatible (`EXCEEDS` / `MATCHED`) due to native VPI RoCE mode.
     - When competitor specifies standard Ethernet, high-speed adapters satisfy basic connectivity.
   - Port count and line-rate speed multipliers are verified strictly ($S_{\text{target}} \ge S_{\text{req}}$ and $P_{\text{target}} \ge P_{\text{req}}$).

## 3. Findings

### [Minor] Finding 1: Thermal Regex Bare `fan kit` Alternate Matches Standard Fans
- **What**: In `_evaluateThermalParity`, the regex `/\b(performance fan|high perf fan|fan kit)\b/i` includes the bare phrase `fan kit`.
- **Where**: `scripts/lib/boq/cross_vendor_transformer.js:554`
- **Why**: When a target BOM contains a standard fan kit (e.g. `P48819-B21 HPE ProLiant DL380 Gen12 Standard Fan Kit`), the description matches `fan kit`, setting `hasHighPerfFans = true`. For high-TDP processors ($\ge 300\text{W}$), this allows a standard fan kit to be accepted as `MATCHED` instead of being flagged as `DEFICIT`.
- **Suggestion**: Narrow the regex to require performance tokens: `/\b(high perf(?:ormance)? fan(?: kit)?|performance fan(?: kit)?)\b/i` and explicitly exclude standard fan descriptions (`!/standard fan/i.test(desc)`).

### [Minor] Finding 2: High-TDP Boundary Gap Between 250W and 299W in `_evaluateThermalParity`
- **What**: In `_evaluateThermalParity`, `isHighTdp` is triggered when `reqCpuTdp >= 250`, but the fan enforcement at line 562 checks `if (reqCpuTdp >= 300 && !hasHighPerfFans)`.
- **Where**: `scripts/lib/boq/cross_vendor_transformer.js:543, 562–566`
- **Why**: For processors with TDP in the range $[250\text{W}, 299\text{W}]$, the function passes the high-TDP entry check, skips the $\ge 300\text{W}$ fan check, skips heatsink existence checks, and falls through to line 566 returning `MATCHED` even if the target BOM contains 0 heatsinks and 0 fans.
- **Suggestion**: Add a basic heatsink presence check (`hasHeatsinks`) for all processors, and align fan kit requirements with the server chassis TDP guidelines ($\ge 250\text{W}$).

## 4. Caveats

1. **Semantic Scope of `STORAGE_CABLING` in Parity Audit**:
   `STORAGE_CABLING` in `AUDIT_SUBSYSTEMS` is mapped to `_evaluateOpticalTransceiverParity` which audits optical transceivers, DAC/AOC interconnect cables, and network cabling kits. Physical storage SAS/SATA/NVMe controller backplane cabling is validated separately by physical aspect checkers (`storage_tri_mode.js`). This is an intentional division of labor, but reviewers should note the terminology mapping.

2. **6 DIMMs per Socket on 12-Channel AMD EPYC (Genoa/Bergamo)**:
   In `workload_dna.js` and `cross_vendor_transformer.js`, supported DIMM populations are defined as `[1, 2, 4, channelWidth, channelWidth * 2]`. On 12-channel AMD architectures, 6 DIMMs per socket (12 DIMMs for 2P) is classified as `UNBALANCED_CHANNEL_POPULATION`. Although AMD BIOS technically boots in 6-channel sub-NUMA / NPS2 mode, flagging it as suboptimal is conservative and safe for enterprise presales, as half-populated memory reduces memory bus bandwidth by 50% relative to 12 DIMMs (1DPC).
