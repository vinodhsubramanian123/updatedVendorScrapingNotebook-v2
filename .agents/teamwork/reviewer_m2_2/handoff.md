## 3. Caveats & Adversarial Edge Cases Noted

During adversarial boundary testing, three minor non-blocking edge cases were identified and documented for future consideration:

1. **Single-PSU Rating Boundary on Extreme Power (>2200W)**:
   - In `_evaluatePowerRepair`, if a single server requires >2200W (e.g. multi-GPU accelerator load requiring 3120W), the substitution selects `P44712-B21` (2200W PSU, the largest Flex Slot unit available), but the text asserts `2200W >= 3120W` with a `-29% reserve`.
   - *Recommendation*: For loads exceeding 2200W, the proof should note that single PSU capacity is exceeded and requires multi-PSU power summing (2+2 N+N redundancy) or chassis power distribution.
2. **Defensive Parameter Nullability**:
   - In `_extractAspects(evalResults = {})`, calling `generateCounterfactualRepairProofs(null)` throws a `TypeError` because JavaScript default parameters only apply to `undefined`.
   - *Recommendation*: Add `const safeResults = evalResults || {};` for fail-safe invocation when called outside try/catch blocks.
3. **Dual DLC and Air Heatsink Kit Suggestion**:
   - If a processor has >350W TDP and both `needsHeatsink` and `needsDirectLiquidCooling` flags are set, both an air heatsink (`P74794-B21`) and DLC cold plate (`P74796-B21`) are recommended.
   - *Recommendation*: In production, DLC supersedes air heatsinks; DLC cold plates should suppress standard air heatsink suggestions.

*None of these caveats constitute integrity violations or blockers for Milestone 2 acceptance.*
